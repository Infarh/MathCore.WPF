```csharp
✓ AddCommand_CreatesAndAddsNewItem()
  └─ Демонстрирует асинхронное создание и добавление элемента
```

### Категория 3: RemoveCommand - Удаление элементов (2 теста)
```csharp
✓ RemoveCommand_RemovesItemFromCollection()
  └─ Демонстрирует удаление элемента
     • Проверяет удаление из коллекции
     • Проверяет событие ItemRemoved

✓ RemoveCommand_CanExecute_OnlyForExistingItems()
  └─ Проверяет что команда доступна только для элементов в коллекции
     • true для существующих элементов
     • false для других элементов
```

### Категория 4: EditCommand - Редактирование (2 теста)
```csharp
✓ EditCommand_InvokesEditorAction()
  └─ Демонстрирует редактирование элемента
     • Проверяет вызов функции Editor
     • Проверяет передачу правильного элемента

✓ EditCommand_CanExecute_OnlyForExistingItems()
  └─ Проверяет доступность команды редактирования
```

### Категория 5: PropertyChanged - Отслеживание изменений (4 теста)
```csharp
✓ ItemPropertyChanged_SubscribesToNewItems()
  └─ Демонстрирует подписку на PropertyChanged при добавлении
     • Коллекция автоматически подписывается на элементы
     • Изменения свойств отслеживаются

✓ ItemPropertyChanged_UnsubscribesFromRemovedItems()
  └─ Проверяет отписку при удалении элементов
     • Изменения удалённых элементов не отслеживаются

✓ ItemPropertyChanged_HandlesReplaceAction()
  └─ Демонстрирует обработку при замене элементов
     • Старый элемент - отписка
     • Новый элемент - подписка

✓ ItemPropertyChanged_HandlesResetAction()
  └─ Демонстрирует обработку при очистке коллекции
     • Переинициализация всех подписок
```

### Категория 6: Dispose - Управление ресурсами (2 теста)
```csharp
✓ Dispose_UnsubscribesAllItems()
  └─ Демонстрирует освобождение ресурсов
     • После Dispose элементы не отслеживаются

✓ Dispose_CanBeCalledMultipleTimes()
  └─ Проверяет безопасность множественных вызовов
     • Не выбрасывает исключение
```

### Категория 7: Интеграционные тесты (2 теста)

```csharp
✓ IntegrationScenario_ComplexOperations()
```
